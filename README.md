# CAD Models for miscellaneous parts

Repository for the **approximate** CAD models I created for various parts from suppliers. Most are available in both Fusion360 and STEP formats.

Details and suppliers can be found in these posts:
* Motors: https://raphtronic.blogspot.com/2026/07/cad-models-specs-motors.html

Feel free to copy, remix, whatever (non-commercially)

Happy CADing to all !
